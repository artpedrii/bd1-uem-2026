# Atividade 3 — JOINs (Resolução)

Usa as tabelas `categoria` e `produto` criadas na Atividade 1.

```text
CATEGORIA(id_categoria PK, nome, ativo)
PRODUTO(id_produto PK, nome, preco, estoque, id_categoria FK, descricao)
```

## Dados de apoio

Na Atividade 1 todas as categorias têm produtos. Para os exercícios de `LEFT JOIN`, criamos duas categorias **sem produtos**:

```sql
INSERT INTO categoria (nome)
VALUES ('Brinquedos'), ('Jardinagem');
```

Agora há 10 categorias e 15 produtos.

---

# Nível 1 — INNER JOIN

## 1. Nome de cada produto e sua categoria

```sql
SELECT p.nome AS produto,
       c.nome AS categoria
FROM produto p
INNER JOIN categoria c
        ON c.id_categoria = p.id_categoria;
```

## 2. Nome, preço e categoria, em ordem decrescente de preço

```sql
SELECT p.nome AS produto,
       p.preco,
       c.nome AS categoria
FROM produto p
INNER JOIN categoria c
        ON c.id_categoria = p.id_categoria
ORDER BY p.preco DESC;
```

## 3. Somente produtos de Informática

```sql
SELECT p.nome AS produto,
       p.preco,
       c.nome AS categoria
FROM produto p
INNER JOIN categoria c
        ON c.id_categoria = p.id_categoria
WHERE c.nome = 'Informática';
```

## 4. Produtos com preço superior a R$ 500 e suas categorias

```sql
SELECT p.nome AS produto,
       p.preco,
       c.nome AS categoria
FROM produto p
INNER JOIN categoria c
        ON c.id_categoria = p.id_categoria
WHERE p.preco > 500;
```

## 5. Produtos de Informática ou Móveis, em ordem alfabética

```sql
SELECT p.nome AS produto,
       c.nome AS categoria
FROM produto p
INNER JOIN categoria c
        ON c.id_categoria = p.id_categoria
WHERE c.nome IN ('Informática', 'Móveis')
ORDER BY p.nome ASC;
```

# Nível 2 — LEFT JOIN

## 6. Todas as categorias, incluindo as sem produtos

```sql
SELECT c.nome AS categoria,
       p.nome AS produto
FROM categoria c
LEFT JOIN produto p
       ON p.id_categoria = c.id_categoria
ORDER BY c.nome;
```

Categorias sem produtos (Brinquedos e Jardinagem) aparecem com `produto = NULL`.

## 7. Categorias sem produtos

```sql
SELECT c.id_categoria,
       c.nome AS categoria
FROM categoria c
LEFT JOIN produto p
       ON p.id_categoria = c.id_categoria
WHERE p.id_produto IS NULL;
```

Após o `LEFT JOIN`, as categorias sem correspondência têm todas as colunas de `produto` como `NULL`. O filtro `IS NULL` na PK de `produto` isola exatamente essas linhas.

## 8. Todas as categorias, associando só produtos com preço > R$ 100

```sql
SELECT c.nome AS categoria,
       p.nome AS produto,
       p.preco
FROM categoria c
LEFT JOIN produto p
       ON p.id_categoria = c.id_categoria
      AND p.preco > 100
ORDER BY c.nome;
```

**Ponto-chave:** a condição `p.preco > 100` fica no **`ON`**, e não no `WHERE`. Assim ela só decide quais produtos se associam, e as categorias sem correspondência continuam aparecendo (com `NULL`). Se fosse no `WHERE`, essas linhas seriam descartadas e o `LEFT JOIN` se comportaria como `INNER JOIN`.

# Nível 3 — Comparações

## 9. INNER JOIN × LEFT JOIN

```sql
-- INNER JOIN
SELECT c.nome AS categoria, p.nome AS produto
FROM categoria c
INNER JOIN produto p ON p.id_categoria = c.id_categoria;

-- LEFT JOIN
SELECT c.nome AS categoria, p.nome AS produto
FROM categoria c
LEFT JOIN produto p ON p.id_categoria = c.id_categoria;
```

**Comparação:**

- `INNER JOIN` retorna **15 linhas**, apenas pares com correspondência. Brinquedos e Jardinagem não aparecem.
- `LEFT JOIN` retorna **17 linhas**: as 15 anteriores mais Brinquedos e Jardinagem, com `produto = NULL`.
- A diferença são as linhas da tabela da esquerda **sem correspondência**.

## 10. LEFT JOIN reescrito como RIGHT JOIN

Original:
```sql
SELECT c.nome AS categoria, p.nome AS produto
FROM categoria c
LEFT JOIN produto p ON p.id_categoria = c.id_categoria;
```

Equivalente com `RIGHT JOIN` (basta **inverter a ordem das tabelas**):
```sql
SELECT c.nome AS categoria, p.nome AS produto
FROM produto p
RIGHT JOIN categoria c ON p.id_categoria = c.id_categoria;
```

O resultado é o mesmo (17 linhas), pois a tabela preservada continua sendo `categoria`.

## 11. CROSS JOIN

```sql
SELECT c.nome AS categoria, p.nome AS produto
FROM categoria c
CROSS JOIN produto p;
```

`CROSS JOIN` gera o **produto cartesiano**: cada linha de uma tabela é combinada com todas as da outra, sem condição.

```text
linhas = 10 categorias × 15 produtos = 150 linhas
```

A maioria das combinações não tem sentido (ex.: "Notebook" com "Livros"). Por isso ele é raramente usado em consultas comuns.

# Nível 4 — Modelagem e consulta

## 12. `cliente` e `pedido` (1:N)

```sql
CREATE TABLE cliente (
    id_cliente   BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nome_cliente VARCHAR(100) NOT NULL
);

CREATE TABLE pedido (
    id_pedido   BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    data_pedido DATE NOT NULL,
    valor_total NUMERIC(10,2) NOT NULL CHECK (valor_total >= 0),
    id_cliente  BIGINT NOT NULL REFERENCES cliente (id_cliente)
);
```

Dados: 3 clientes (Carla ficará sem pedidos) e 4 pedidos.

```sql
INSERT INTO cliente (nome_cliente)
VALUES ('Ana'), ('Bruno'), ('Carla');
-- Ana = 1 | Bruno = 2 | Carla = 3

INSERT INTO pedido (data_pedido, valor_total, id_cliente)
VALUES
    ('2026-11-01', 3650.00, 1),
    ('2026-11-08', 120.00,  1),
    ('2026-11-05', 2200.00, 2),
    ('2026-11-15', 89.90,   2);
```

**a) Pedidos com seus clientes**
```sql
SELECT p.id_pedido, p.data_pedido, p.valor_total, c.nome_cliente
FROM pedido p
INNER JOIN cliente c ON c.id_cliente = p.id_cliente;
```

**b) Todos os clientes, inclusive sem pedidos**
```sql
SELECT c.nome_cliente, p.id_pedido, p.data_pedido, p.valor_total
FROM cliente c
LEFT JOIN pedido p ON p.id_cliente = c.id_cliente;
```

**c) Apenas clientes sem pedidos**
```sql
SELECT c.id_cliente, c.nome_cliente
FROM cliente c
LEFT JOIN pedido p ON p.id_cliente = c.id_cliente
WHERE p.id_pedido IS NULL;
```
Resultado esperado: **Carla**.

**d) Pedidos ordenados por data**
```sql
SELECT p.id_pedido, p.data_pedido, c.nome_cliente
FROM pedido p
INNER JOIN cliente c ON c.id_cliente = p.id_cliente
ORDER BY p.data_pedido;
```

**e) Pedidos de um cliente específico (Ana)**
```sql
SELECT p.id_pedido, p.data_pedido, p.valor_total
FROM pedido p
INNER JOIN cliente c ON c.id_cliente = p.id_cliente
WHERE c.nome_cliente = 'Ana';
```
