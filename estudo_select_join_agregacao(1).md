# PARTE 1 — RESUMO

## 1.1 SELECT

```sql
SELECT   colunas            -- o que mostrar
FROM     tabela             -- de onde
WHERE    condição           -- filtra LINHAS
ORDER BY coluna [ASC|DESC]  -- ordena
LIMIT    n;                 -- limita quantidade
```

| Quero | Uso |
|---|---|
| Todas as colunas | `SELECT *` |
| Colunas específicas | `SELECT nome, preco` |
| Apelido | `SELECT preco AS valor` |
| Sem repetidos | `SELECT DISTINCT id_categoria` |
| Comparação | `= <> > < >= <=` |
| E / OU / NÃO | `AND`, `OR`, `NOT` |
| Lista de valores | `WHERE id_categoria IN (1, 6)` |
| Intervalo | `WHERE preco BETWEEN 100 AND 500` |
| Texto | `WHERE nome LIKE 'M%'` (`%` = qualquer coisa; `ILIKE` ignora maiúscula) |
| Nulo | `WHERE col IS NULL` / `IS NOT NULL` (**nunca** `= NULL`) |
| Ordenar | `ORDER BY preco DESC, nome ASC` |
| Top N | `ORDER BY preco DESC LIMIT 3` |

- Texto fica entre **aspas simples**: `'Informática'`.
- Cálculo na consulta: `SELECT preco * estoque AS valor_estoque`.

## 1.2 JOIN

```sql
SELECT p.nome, c.nome AS categoria
FROM produto p
INNER JOIN categoria c ON c.id_categoria = p.id_categoria;
```

- **ON** liga a FK à PK. Use **alias** (`p`, `c`) e prefixe as colunas (`p.nome`).

| JOIN | Retorna |
|---|---|
| `INNER JOIN` | só linhas com correspondência nas duas tabelas |
| `LEFT JOIN` | **todas** da esquerda + correspondências (sem par → `NULL`) |
| `RIGHT JOIN` | **todas** da direita (= LEFT com as tabelas trocadas) |
| `CROSS JOIN` | todas as combinações (A × B), sem `ON` |

**Padrões que mais caem:**
```sql
-- Quem NÃO tem correspondência (categorias sem produtos)
SELECT c.nome
FROM categoria c
LEFT JOIN produto p ON p.id_categoria = c.id_categoria
WHERE p.id_produto IS NULL;

-- Filtro sem perder o LEFT: condição no ON
... LEFT JOIN produto p ON p.id_categoria = c.id_categoria AND p.preco > 100
```
- Condição no **`ON`** → só filtra o que se associa (mantém a esquerda inteira).
- Condição no **`WHERE`** → descarta linhas, e o LEFT vira INNER.
- Três tabelas: encadeie `JOIN ... ON ... JOIN ... ON ...`.
- Linhas do CROSS JOIN = linhas A × linhas B.

## 1.3 AGREGAÇÃO

| Função | Faz |
|---|---|
| `COUNT(*)` | conta **linhas** |
| `COUNT(col)` | conta **não nulos** da coluna |
| `COUNT(DISTINCT col)` | conta valores diferentes |
| `SUM(col)` | soma |
| `AVG(col)` | média (`ROUND(AVG(col),2)`) |
| `MIN(col)` / `MAX(col)` | menor / maior |
| `STRING_AGG(nome, ', ' ORDER BY nome)` | junta em texto |
| `COUNT(*) FILTER (WHERE cond)` | conta só quem atende à condição |

```sql
SELECT id_categoria, COUNT(*) AS qtd, AVG(preco)
FROM produto
WHERE preco > 100          -- filtra LINHAS (antes de agrupar)
GROUP BY id_categoria      -- toda coluna não agregada do SELECT entra aqui
HAVING COUNT(*) >= 3       -- filtra GRUPOS (depois de agregar)
ORDER BY qtd DESC;
```

**Ordem de execução:** `FROM/JOIN → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT`

**Regras de ouro:**
1. **WHERE** não aceita função de agregação. Use **HAVING**.
2. Coluna no SELECT sem função de agregação **precisa** estar no `GROUP BY`.
3. **`COUNT(*)` no LEFT JOIN conta a linha vazia (NULL) como 1.** Use `COUNT(p.id_produto)`.
4. **Empate no mínimo/máximo:** `WHERE preco = (SELECT MIN(preco) FROM produto)`. `LIMIT 1` perde empates.
5. `SUM`/`AVG` de grupo vazio dá `NULL` → `COALESCE(SUM(x), 0)`.
6. **Valor do estoque:** `SUM(preco * estoque)`.
7. **Agregar sobre agregado** (ex.: ticket médio): calcule o valor por pedido primeiro (CTE) e depois agrupe por cliente:
```sql
WITH pedido_total AS (
  SELECT id_pedido, SUM(quantidade * preco_unitario) AS valor
  FROM item_pedido GROUP BY id_pedido
)
SELECT ... FROM cliente c
LEFT JOIN pedido p ON ... LEFT JOIN pedido_total pt ON ...
GROUP BY c.id_cliente, c.nome_cliente;
```

## 1.4 Checklist para qualquer questão
1. **Quais tabelas?** Se for mais de uma → JOIN (qual preservar? INNER ou LEFT?).
2. **Filtro de linha?** → WHERE (ou ON, se for LEFT JOIN).
3. **Precisa agrupar?** → GROUP BY + função de agregação.
4. **Filtro sobre resultado agregado?** → HAVING.
5. **Ordem/limite?** → ORDER BY / LIMIT.

WITH pedido_total AS (
  SELECT id_pedido, SUM(quantidade * preco_unitario) AS valor
  FROM item_pedido GROUP BY id_pedido

FROM cliente c

GROUP BY c.id_cliente, c.nome_cliente;

WITH pedido_total AS (
  SELECT id_pedido, SUM(quantidade * preco_unitario) AS valor
  FROM item_pedido GROUP BY id_pedido
)
SELECT c.nome_cliente, SUM(pt.valor) AS total_gasto
FROM cliente c
JOIN pedido p        ON p.id_cliente = c.id_cliente
JOIN pedido_total pt ON pt.id_pedido = p.id_pedido
GROUP BY c.id_cliente, c.nome_cliente

WITH vendas AS (
  SELECT pr.nome, SUM(i.quantidade) AS qtd_vendida
  FROM item_pedido i
  JOIN produto pr ON pr.id_produto = i.id_produto
  GROUP BY pr.id_produto, pr.nome
)
SELECT nome, qtd_vendida
FROM vendas
WHERE qtd_vendida = (SELECT MAX(qtd_vendida) FROM vendas);      -- Mouse sem fio (7)

# Dicas para a prova prática

- Leia o enunciado e escreva **quais tabelas e colunas** você precisa antes de digitar.
- Rode a consulta e **confira se o resultado faz sentido** (ex.: nenhuma categoria vazia sumiu quando deveria aparecer?).
- Deu erro `column must appear in the GROUP BY clause`? Falta uma coluna no `GROUP BY`.
- Deu erro `ambiguous column`? Falta o prefixo da tabela (`p.nome`).
- Aspas simples para texto (`'Informática'`), nunca aspas duplas.
- Se travar numa questão, passe para a próxima e volte depois.
